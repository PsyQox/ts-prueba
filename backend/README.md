# Typescript start
* npm init -y (Only don't have package.json)
* npm install typescript -D
* Add in package.json ->  "tsc": "tsc", (In scrips)
* npm run tsc -- --init (Inicialiced proyect, --init is aplicated in tsc, create tsconfig.json)
* npm install ts-node-dev -D
* "dev": "ts-node-dev src/index.ts" //En los scrips
* "start": "node build/index.js", //En los scrips
